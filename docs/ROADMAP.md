# 路线图与未决事项

main 开发分支收敛为 Zotero 正常 PDF 阅读器的当前论文助手，提供单篇 AI、对话、提示词、笔记和手动状态标签。文库查找与切换由 Zotero 负责；插件不枚举完整文库，库列表不挂载阅读室。旧关注字段和后端目录/批量 API 仅兼容保留，没有界面入口或后台触发，不做旧数据迁移清理。正式版本仍为 0.2.0；本轮实机验收待完成。下表列出后续验证或设计事项，不是交付承诺。

| 方向 | 下一步与完成标准 |
| --- | --- |
| 宿主兼容性 | 在初始目标 Zotero 10.0.7 执行实机清单并记录；扩大范围前逐版本验证 |
| 当前附件与生命周期 | 核对同论文多 PDF、多个标签、库列表禁用、未就绪后重试、折叠/展开、重载和关闭；不得回退到其他附件或增加文库导航 |
| 分页与 PDF | 补充公开可分发的合成 PDF；核对 PDF worker 输出变化、印刷页码和无分页情况 |
| 阅读质量 | 用有许可的公开评估集衡量候选证据、遗漏和错误；保持推断、摘录与人工结论分开 |
| 图表与代码 | 当前保留正文证据导航及按需内联原页预览，不提供独立图表卡片或视觉理解；后续再评估精确裁图和多模态能力，不提供公式证明或代码正确性保证 |
| AI 展示精简 | 验收固定五项人工核对框、范围详情/章节矩阵与独立图表卡片的移除；保留简要真实文字覆盖、内联证据及笔记；“精读重点”沿用现有具体核对问题要求，模型质量另行评估 |
| 状态备份与迁移 | 设计可回滚迁移、快照导入和冲突处理；当前不提供自动双向同步 |
| 模型兼容性 | 对 OpenAI 兼容、Anthropic Messages、Gemini、Ollama 分别记录明确测试过的服务/模型版本、模型发现、JSON 支持与取消行为；启动和普通阅读仍禁止探测，禁止下载模型 |
| 可访问性与语言 | 完成真实宿主键盘和屏幕阅读器核查、更多英文界面覆盖 |
| GitHub 分发 | 默认 commit/push；正式版本号、tag 和 Release 仅在得到明确允许后操作，保留 MIT、隐私和测试证据 |
| 自动更新 | 已配置宿主要求的 Release 更新地址并生成清单；待后续版本验证真实升级和回退流程 |
| 官方插件目录 | 按届时要求准备许可证、支持信息、README、Release、兼容性与下载/更新 URL，再申请人工审核；当前未声称收录 |

新网络服务、群组写入、后台批处理或改变数据边界的功能必须先记录产品选择、隐私影响与失败恢复方案，不能沿用首版的授权假设。
