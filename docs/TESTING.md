# 验证清单

公开自动测试只使用 `tests/fixtures/` 与临时生成的虚构文件：不连接实际 Zotero，不读取真实 profile、文库或 PDF，也不发出网络请求。任何个人文库的实际测试记录必须在发布前脱敏，仅保留版本、行为结论和无敏感信息的错误码。

## 自动检查

运行 `npm test`、`npm run check`、`npm run build`。测试覆盖纯逻辑、服务的拒绝/失败路径，以及标准 ZIP 和包完整性。具体用例以测试源码为准。Node 22 为 CI 目标，维护者本地的其他 Node 版本通过不能替代 CI Node 22 结果。

## 安全与隐私复核

- 检查生成的 XPI 清单只有运行时源文件，未包含文库、profile、密钥、日志、PDF、截图、测试或文档。
- 用 ZIP 工具完整性检查及 SHA-256 校验验证发布产物，重复构建比较字节。
- 检查模型错误、日志、导出、状态和笔记中不存在密钥；不要在公开测试中放入真密钥。
- 检查模型输出按数据处理；恶意 HTML、命令或伪造引文不会成为可执行动作或已核实结论。
- 检查状态写入失败保留旧值，插件拥有的笔记发生冲突时停止覆盖。
- 公开证据只记录脱敏结论，禁止真实库标题、论文正文、用户路径、截图或完整日志。
